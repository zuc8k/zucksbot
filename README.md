#ZUCKS 🤖

Open source discord bot tied to a web control panel — written with **TypeScript**.

## Features

- 📊 Full control panel in Arabic

- 🔐 Secure Login + Sessions

- 🗄️ MariaDB database (compatible with HeidiSQL)

- 📝 Automatically record events

- ⚡ Internal API for statistics

- 🎨 Modern dark facade

- 🟦 **TypeScript** with full types (Strict Mode)

## Operation

```bash

Git clone https://github.com/zuc8k/zucksbot

Cd zucks

Npm install

Cp .env.example .env

# Edit .env token mode and MariaDB data

Npm run build

Npm start
